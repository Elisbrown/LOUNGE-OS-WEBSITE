# Content pages generator

The feature, solution, country, French and blog pages (everything under
`/features/`, `/blog/`, `/fr/`, `/pricing/`, `/cameroon/`, …) are generated from
the Markdown files in `content/` by `build.py`. The homepage (`index.html`) and
the legal, documentation and knowledge base pages are edited by hand.

## Add or edit a page

1. Copy an existing file in `content/en/blog/` (or another folder) and edit the
   front matter (`url`, `title`, `description`, `h1`, `published`, `image`, …)
   and the Markdown body.
2. Shortcodes you can use in the body:
   - `[[figure:loungeos-kitchen-display-system|Alt text|Caption]]`: a screenshot from `/images/screens/`
   - `[[cta]]`: the free-trial call-to-action box
   - `[[cards:/url-one/,/url-two/]]`: cards linking to other pages
   - `[[include:plans]]` / `[[include:price_table]]`: the plan cards (with the monthly/yearly toggle) and the US$/FCFA price table
3. A `## Frequently asked questions` (or `## Questions fréquentes`) section with
   `###` questions becomes FAQ structured data automatically.
4. Link translations with `alternates: {fr: /fr/…/}`; the reverse link is added for you.
5. Build from the repository root:

   ```
   pip install markdown pyyaml beautifulsoup4
   python3 scripts/site/build.py
   python3 scripts/seo_update.py
   ```

`build.py` refuses to build if a linked page, related card or translation does
not exist.

## Prices

There are three plans (Starter, Business, Pro), each monthly or yearly, in US$ and
FCFA. Visitors in Cameroon see FCFA; everyone else sees US$. The prices appear in
these places. Change them together:

- `PLANS` in the pricing section of `/app.js` (what visitors see after the page loads)
- `PRICES` and `TRIAL_DAYS` in `build.py` (the plan cards, the price table and the
  JSON-LD offers on generated pages), plus any amounts written in the Markdown in `content/`
- the hand-edited pricing cards and JSON-LD offers in `index.html`, `documentation.html`
  and `knowledgebase.html`

Payments, invoices and plan changes happen at `account.loungeos.app`; the "Start free
trial" buttons go to `app.loungeos.app/login`.

## Sitemap, robots.txt, feed and llms.txt

These are generated by `scripts/seo_update.py`, and the **SEO refresh** GitHub
Action (`.github/workflows/seo-refresh.yml`) runs it on every push to `main` and
daily. Each page's `lastmod` and "Updated" date come from its last real commit.
Don't edit those files by hand.

## CSS and JavaScript versions

Every page links `/style.css?v=…` and `/app.js?v=…`, where `v` is a hash of the
file. When you change `style.css` or `app.js`, run `python3 scripts/seo_update.py`
(or let the GitHub Action do it after you push) so the hash changes and browsers
download the new file instead of reusing an old cached copy. Without this,
returning visitors can see new pages with the old stylesheet.

## Link preview images

Every page has its own share card at `images/og/<slug>.webp` (1200×630): the
page's screenshot with the logo, category label and title. That's what shows
when a link is shared on WhatsApp, Facebook, LinkedIn, X, Telegram or iMessage.
`scripts/seo_update.py` adds the og:image and twitter:image tags. After adding a
page or changing a title, regenerate the cards:

```
node scripts/og/make-og.js            # or: node scripts/og/make-og.js /new-page/
python3 scripts/og/to_webp.py
python3 scripts/seo_update.py
```
