# Content pages generator

The feature, solution, country, French and blog pages (everything under
`/features/`, `/blog/`, `/fr/`, `/pricing/`, `/cameroon/`, …) are generated from
the Markdown files in `content/` by `build.py`. The homepage (`index.html`) and
the legal, documentation and knowledge base pages are edited by hand.

## Add or edit a page

1. Copy an existing file in `content/en/blog/` (or another folder) and edit the
   front matter (`url`, `title`, `description`, `h1`, `published`, `image`, …)
   and the Markdown body.
2. Shortcodes you can use in the body:
   - `[[figure:loungeos-kitchen-display-system|Alt text|Caption]]`: a screenshot from `/images/screens/`
   - `[[cta]]`: the free-trial call-to-action box
   - `[[cards:/url-one/,/url-two/]]`: cards linking to other pages
   - `[[include:plans]]` / `[[include:price_table]]`: pricing cards and regional price table
3. A `## Frequently asked questions` (or `## Questions fréquentes`) section with
   `###` questions becomes FAQ structured data automatically.
4. Link translations with `alternates: {fr: /fr/…/}`; the reverse link is added for you.
5. Build from the repository root:

   ```
   pip install markdown pyyaml beautifulsoup4
   python3 scripts/site/build.py
   python3 scripts/seo_update.py
   ```

`build.py` refuses to build if a linked page, related card or translation does
not exist.

## Prices

Regional prices appear in three places. Change them together:

- `REGIONAL_PRICING` and `USD_TIERS` at the top of the pricing section in `/app.js`
  (what visitors see)
- `PRICES` in `build.py` (the static tables on the pricing and country pages) and
  the country pages' own tables in `content/`
- the amounts charged by `account.loungeos.app/checkout`, which receives
  `region` and `currency` query parameters from the site

## Sitemap, robots.txt, feed and llms.txt

These are generated by `scripts/seo_update.py`, and the **SEO refresh** GitHub
Action (`.github/workflows/seo-refresh.yml`) runs it on every push to `main` and
daily. Each page's `lastmod` and "Updated" date come from its last real commit.
Don't edit those files by hand.
